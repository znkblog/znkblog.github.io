

## 힙(Heap)


참고로 0 인덱스를 힙 자료구조의 루트로 삼았다. 이 경우 부모 인덱스 `p`와 자식 인덱스 `c1`, `c2`의 관계는 아래와 같다.
``` python
p = ((c1 or c2) - 1) // 2
c1 = (p + 1)*2 - 1 = 2*p + 1
c2 = c1 + 1
```

더 상세한 설명은 나무위키의 [힙 트리](https://namu.wiki/w/%ED%9E%99%20%ED%8A%B8%EB%A6%AC) 문서를 참고하자. (단, 이 문서에서는 힙 자료구조의 배열표현을 설명하는 그림에서 1번 인덱스를 루트로 보고 설명하고 있어 헷갈릴 수 있으니 주의)
