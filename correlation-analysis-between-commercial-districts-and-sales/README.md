# 상권분석 위한 기초자료
- 전국 일반음식점 인허가 자료 위치: [공공데이터포털](https://www.data.go.kr/data/15045016/fileData.do) 접속 -> `바로가기` 클릭 -> 새로 열리는 화면에서 `전국 파일 다운로드` 클릭
  - 파일명: `식품_일반음식점.csv`, 파일크기: 약 680MB
- `식품_일반음식점.csv` 기본정보
  - 좌표계: 보정계수 안들어간 Bessel 중부원점TM(EPSG:5174)
  - 인코딩: python 스크립트 통해 utf-8-sig 로 변환
  - 필요칼럼: `영업상태명`, `좌표정보(X)`, `좌표정보(Y)`

# 매출데이터
- 실제 사내매출데이터가 아닌 fake 매출데이터 사용
  - 파일명: `매출정보.csv`
  - 좌표계: WGS84 (위도/경도 좌표계)
  - 필요칼럼: `매출액`, `좌표정보(X)`, `좌표정보(Y)`
