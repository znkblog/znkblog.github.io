# 프로젝트 작업 지침

## 공통 작업 원칙

- Python 3.10 이상을 지원하고 Python 프로젝트 초기화와 의존성 관리는 `uv`로 하세요. 의존성은 `pyproject.toml`과 `uv.lock`에서 관리하고, 설치에는 `uv sync`를 사용하세요.
- 스크립트는 실행 순서에 맞춰 번호를 붙입니다. 인코딩 변환은 `01_convert_to_utf8.py`, 격자 집계는 `02_analyze_restaurant-grids.py`, 매출 격자 매칭은 `03_attach_sales_to_grids.py`입니다.
- 원본 파일 `식품_일반음식점.csv`는 약 680MB이므로 수정하지 마세요. 대용량 CSV는 전체를 메모리에 올리지 말고 스트리밍 또는 청크 단위로 처리하세요.
- `README.md`는 사용자가 직접 작성한 파일입니다. 사용자가 명시적으로 요청하지 않는 한 수정하지 마세요.
- 사용자가 질문만 한 경우에는 질문에 답하고, 파일 수정이나 스크립트 실행은 명시적으로 요청한 경우에만 하세요.
- 분석 결과를 발표 자료로 요청하면 별도 스크립트가 아니라 요청에 맞는 PPTX를 직접 작성합니다. 출력은 기본적으로 한 장이며, 차트·핵심 통계·해석을 간결하게 배치하고 실제 생성 파일을 검증하세요.
- PPTX의 한글이 올바르게 표시되도록 한글 글꼴을 지정하고, 설명 텍스트 상자는 자동 줄바꿈을 설정해 슬라이드 영역 안에 들어가도록 하세요.

## CSV 인코딩 변환

- `01_convert_to_utf8.py`는 `식품_일반음식점.csv`를 읽어 `식품_일반음식점_utf-8.csv`로 변환합니다. 출력은 Excel에서 UTF-8로 인식할 수 있도록 UTF-8-SIG(BOM 포함) 인코딩으로 저장합니다.
- 원본 인코딩은 모를 수 있으므로 기본적으로 자동 감지하고, 필요하면 `--source-encoding` 옵션으로 지정할 수 있게 하세요(예: `cp949`).
- CSV 내용과 줄바꿈은 유지하고 인코딩만 UTF-8로 변경하세요. `uv run .\01_convert_to_utf8.py`로 실행합니다.

## 음식점 좌표 격자 집계

- `02_analyze_restaurant-grids.py`는 `식품_일반음식점_utf-8.csv`에서 `영업상태명`이 `영업/정상`인 행의 `좌표정보(X)`, `좌표정보(Y)`를 추출합니다. 좌표 문자열 앞뒤 공백을 제거하고, EPSG:5174 좌표를 그대로 사용합니다.
- 파일을 스트리밍 방식으로 두 번 읽어 유효 좌표의 범위와 격자별 음식점 수를 계산합니다. 유효하지 않거나 비어 있는 좌표는 집계에서 제외하고 개수를 알립니다.
- 격자 크기는 1km입니다. 시작 X는 `floor(최솟값 X / 1000) * 1000`, 시작 Y는 `ceil(최댓값 Y / 1000) * 1000`으로 계산합니다. X는 왼쪽 경계 포함·오른쪽 경계 미포함, Y는 위쪽 경계 포함·아래쪽 경계 미포함으로 각 좌표를 한 격자에 배정합니다.
- 모든 격자를 ID와 함께 `격자배치결과.csv`에 저장하며 음식점이 없는 격자도 포함합니다. 출력 인코딩은 엑셀에서 바로 열 수 있도록 UTF-8-SIG를 사용합니다.
- `uv run .\02_analyze_restaurant-grids.py`로 실행합니다.

## 매출 좌표 격자 매칭

- `03_attach_sales_to_grids.py`는 `매출정보.csv`의 `매출액`, `좌표정보(X)`, `좌표정보(Y)`를 읽습니다. 값의 앞뒤 공백을 제거하고 WGS84(EPSG:4326, X=경도·Y=위도) 좌표를 EPSG:5174로 변환합니다.
- 매출 CSV는 한 행씩 읽고, 격자 정보만 메모리에 올려 위치에 해당하는 격자의 `격자ID`와 `음식점카운팅`을 매출액 행에 붙입니다. 매출을 격자별로 합산하지 않습니다.
- 출력은 `매출액`, `격자ID`, `음식점카운팅` 열만 포함한 `격자매출배치결과.csv`이며, Excel 호환을 위해 UTF-8-SIG로 저장합니다. 좌표가 유효하지 않거나 격자에 매칭되지 않는 매출 행은 결과에서 무시(제외)하고 건수를 알립니다.
- 좌표 변환에는 `pyproj`를 사용합니다. 실행은 `uv run .\03_attach_sales_to_grids.py`입니다.

## 매출액과 음식점 밀도 상관관계 발표 자료

- `격자매출배치결과.csv`를 사용해 매출액과 음식점 밀도(1km²당 음식점 수)의 상관관계를 분석하고, 결과를 한 장의 PPTX로 작성합니다.
- 산점도에서 매출액을 X축, 음식점 밀도를 Y축으로 표시하고, 전체 분포와 밀집 구간을 읽기 쉽게 보여줍니다. 상관계수와 통계적 유의성, 표본 수, 결과 해석 및 상관관계가 인과관계를 뜻하지 않는다는 주의사항을 포함합니다.
- 실제 CSV의 행을 분석해 수치와 해석을 산출합니다. 음식점 밀도가 0인 격자와 극단값 등 분포 특성을 확인해 시각화에 반영하고, 축 단위와 값의 의미를 명시합니다.
