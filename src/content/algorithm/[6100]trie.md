## 트라이 자료구조

최신 포털사이트 검색창에 뭔가를 입력하면, 사용자가 최종적으로 입력할 것이라고 예상되는 예상 검색어가 팝업으로 뜨기도 함,

일종의 자동완성 기능인데, 유저들이 많이 찾는 검색어를 데이터베이스 등에 간직하고 있다가, 키인을 하면 빠르게 키인한 철자가 포함되어 있는 검색어를 찾아냄, 속도가 중요,

[나무위키](https://namu.wiki/w/%ED%8A%B8%EB%9D%BC%EC%9D%B4) 사이트 안에 있는 그림을 보면 알 수 있듯, 트라이 자료구조는 문자열이나 단어를 철자 단위로 분해한 다음, 철자별로 위에서부터 트리구조를 만들어서 확대해 나가는 데이터셋임,

예를들어 "가구", "가물치", "나무" 와 같은 단어들을 트라이 자료구조로 만들었다면, 대략 아래와 유사한 구조를 보임, (위 나무위키의 그림은 자식 노드의 값이 부모 노드의 값까지 포함하고 있으나, 여기서는 이어지는 단어 철자 하나만을 가지고 있도록 표현함)

```text
         root
           |
        +--+----+
        |       |
        가      나
        |       |
     +--+--+    무
     |     |
     구    물
           |
           치
```

내가 "가" 라고 입력했을 경우, 트라이 자료구에서 일단 "가" 노드로 진입하고, 그 아래로 다음 철자인 "구" 와 "물" 을 자식노드로 가지고 있음, 자동완성 입장에서 생각해보면, 여기부터 모든 자식노드를 추적하여 최종 완성될 가능성이 있는 단어나 문자열을 미리 보여줄 수 있게 됨, 모든 검색어를 그냥 나열해놓은 데이터셋보다는 검색속도가 빠를 수밖에 없음,

## 코드 구현

단어들로 트라이 자료구조를 만든다고 보면, 단어들을 트라이 구조에 넣는 push, 사용자가 입력하는 텍스트에 따라 노드를 탐색하여, 어떤 단어가 트라이 자료구조에 있는지 반환하는 find 구현이 필요함,

함수 구현에 앞서, 노드는 구조체로서 최소한 아래 속성을 가지고 있어야 함,

> - end: 단어의 끝인지 여부
> - children: 현재의 노드 다음에 이어지는 노드 집합

end 속성이 필요한 이유는, 예를들어 "뉴스" 와 "뉴스페이퍼" 두 단어를 트라이 자료구조에 push 했다고 해보면, `뉴->스->페->이->퍼` 과 같은 식으로 노드가 연결됨, 여기서 사용자가 "뉴" 를 입력했다면, 자동완성 기능이 "뉴스" 와 "뉴스페이퍼" 두개를 출력해야하는데, 입력되었던 단어 정보를 모르는 find 함수는 어디까지 단어라보고 출력을 해줘야하는지 알 수 없는 문제가 발생함,

만일 `스` 를 나타내는 노드의 end 속성이 True 라면, find 함수는 일단 `스` 에서 끝나는 단어가 있었구나 알기에 "뉴스" 를 출력할 수 있고, 계속 이어나가다가 마지막 `퍼` 도 True 라면 "뉴스페이퍼" 도 출력하게 됨, push 했던 단어의 끝을 알려줘야 자동완성에 필요한 find 도 제대로 동작할 수 있음,

아래부터 코딩테스트 문제로 구체적 코드 구현을 함,

## leetcode: 14. Longest Common Prefix

[https://leetcode.com/problems/longest-common-prefix/](https://leetcode.com/problems/longest-common-prefix/)

여러 단어들을 원소로 가진 strs 데이터셋에서, 모든 원소들이 공통으로 지닌 접두어 (prefix) 를 찾아내는 문제임,

다양한 방법들로 문제를 해결할 수도 있지만, 여기서는 트라이 자료구조를 활용한 풀이를 소개함,

```python
class TrieNode:
    def __init__(self):
        self.end = False
        self.children = {}

class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        trie = TrieNode()

        # push
        for str in strs:
            n = trie
            for x in str:
                n = n.children.setdefault(x, TrieNode())
            n.end = True

        # find
        a = ""
        n = trie
        while not n.end and len(n.children) == 1:
            k = list(n.children.keys())[0]
            a += k
            n = n.children[k]

        return a
```

트라이 자료구조 노드를 TreeNode 클래스로 정의함, end 는 해당 노드가 어떤 단어의 끝이었음을 나타내고, children 은 후속 노드들로 무엇들이 이어져있는지를 딕셔너리 `{철자: TrieNode, ... }` 구조로 나타냄, 그리고 최상위 노드를 생성하고 trie 라는 변수에 할당함,

push 를 구현한 코드를 보면, 단어를 순회하면서, 최상위 노드부터 알파벳을 따라 계속 노드를 이어붙여나감, 이미 알파벳에 자식 노드에 있다면 다음 노드로 넘어가고 없다면 해당 알파벳 노드를 새로 생성하여 부모 노드 children 속성에 삽입하고 다음 노드로 진행함,

안쪽루프 순회가 종료되었다면 단어 한개의 트라이 자료구조 삽입이 끝났다는 의미이므로, 그 때의 노드의 end 속성을 True 로 치환하고, 다음 단어 push 를 계속 반복,

find 함수는 문제에서 요구한대로, 모든 단어들의 공통 접두어를 찾기 위해, 최상위 노드부터 시작, end 가 아니면서 children 수가 1 개일 때만을 계속 추적해 감,
