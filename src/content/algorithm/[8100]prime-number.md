## 소수 구하는 법

가장 쉽게 구할 수 있는 방법은, 어떤 수 n 이 소수의 정의에 부합하는가를 따져보는 방법임, 이 수를 2 부터 계속 나눠보면 됨, 나머지가 0 이되는 수 i 가 나온다면, i 는 n 의 약수인 것이고, 이는 소수의 정의(1 과 자기자신만을 약수로 가지는 자연수)에 부합하지 않으므로 소수가 아님,

그러나 소수를 구하는 가장 유명한 알고리즘은 에라토스테네스의 체 (Sieve of Eratosthenes) 임, 간단히 얘기하자면, 소수가 될 수 있는 가장 작은 자연수인 2 부터 시작해서 2 의 배수를 몽땅 지움, 다음으로 3 의 배수도 몽땅 지움, 이제 4 의 배수 차례인데 이미 2 때문에 모두 지워져 있음, 그 다음 수인 5 의 배수를 몽땅 지움, 6 의 배수도 이미 지워져 있음, ... 식으로 소수를 찾아내는 방법임,

마치 숫자들을 체에 넣고 소수의 배수들을 걸러내는 것과 비슷해 보이기 때문에, 에라토스테네스의 체라는 이름이 붙은 게 아닐까 함, 더 자세한 사항을 알고 싶다면 [나무위키](https://namu.wiki/w/%EC%97%90%EB%9D%BC%ED%86%A0%EC%8A%A4%ED%85%8C%EB%84%A4%EC%8A%A4%EC%9D%98%20%EC%B2%B4)를 참고할 것,

## 코드 구현

에라토스테네스의 체 방식으로 n 까지의 자연수에서 소수를 구하는 코드를 생각해보기로 함, 이중루프를 사용하면 된다는 것은 쉽게 이해될 것인데, 중요한 건 바깥쪽 루프와 안쪽 루프의 순회 범위를 어떻게 설정하느냐에 따라 효율성이 달라짐,

바로 떠로으는 방법은 아래와 같을 것임,

```python
for x in range(2, n+1):
    for y in range(x*2, n+1, x):
        # y 를 소수 후보에서 지우는 코드
```

바깔루프부터 보면, n + 1 미만까지 진행할 필요가 없음, 안쪽 루프에서는 x 의 배수인 y 를 소수 후보에서 지우게 되는데, 간단한 수학상식을 생각해보면 x 의 배수 중에서 가장 작은 수는 x * 2 이므로, x 가 n // 2 를 넘어서는 순간부터는 x 의 배수는 무조건 n 을 넘어가 버림, 이렇게 생각하면 `range(2, n//2 + 1)` 로 바꾸는 게 좋음,

이제 안쪽 루프를 생각해보면, x 의 배수를 지울 때 x * 2 는 2 의 배수를 지울 때 이미 지워졌을 것임, 예를들어 x 가 11 이고, 11 의 배수인 수들을 지운다고 해보면, 11 * 2 인 22 는 이미 앞선 순회 즉 x 가 2 일 때 지워진 값임, 그리고 11 * 3 도, ... 11 * 10 까지도 이미 다 지워진 값들임, 11 * 11 부터 생각하면 됨, 즉 x * x 부터 지워가면 되기 때문에 `range(x*x, n+1, x)` 로 바꿔줄 수 있음,

여기서 끝이 아님, 안쪽루프를 바꿨다면 바깥루프를 한번 더 바꿔줄 수 있음, 예를들어 n 이 100 이라고 한다면, 바깥루프는 50 까지는 순회함, 문제는 안쪽루프의 시작이 x * x 이고 이 경우는 2500 이 되며, 이는 n 을 아득히 초과해버림, 이 케이스라면 안쪽루프는 실행될 여지가 아예없음, x * x 가 n 이내이어야 안쪽루프 순회에 의미가 있으므로, 바깥쪽 루프도 `range(2, int(n ** 0.5)+1)` 로 범위를 더 좁힐 수 있음,

종합하면...

```python
for x in range(2, int(n ** 0.5)+1):
    for y in range(x*x, n+1, x):
        # y 를 소수 후보에서 지우는 코드
```

## leetcode: 204. Count Primes

[https://leetcode.com/problems/count-primes/](https://leetcode.com/problems/count-primes/)

주어진 n 미만까지 소수의 개수를 리턴하는 문제임,

python 풀이는 아래와 같음,

```python
class Solution:
    def countPrimes(self, n: int) -> int:
        if n < 2:
            return 0

        isPrime = [1]*(n+1)
        isPrime[0] = isPrime[1] = 0

        for x in range(2, int(n ** 0.5)+1):
            if isPrime[x] == 1:
                for y in range(x*x, n+1, x):
                    isPrime[y] = 0

        return sum(isPrime[:-1])
```

위에서 언급한 에라토스테네스의 체 방식을 사용하였음, isPrime 리스트는 해당 인덱스가 소수라면 1, 아니라면 0 을 입력, 2 이상은 일단 1 로 보았다가 소수의 배수들은 모두 0 으로 치환하는 방식임,

문제에서는 n 미만의 소수의 개수를 리턴하도록 되어있으므로, 마지막 n 인덱스를 제외한 1 의 합계를 리턴하도록 함,

위 에라토스테네스의 체 방식은 n 이라는 숫자가 특정되어있어야 구할 수 있는 방법임, 만일 n 이 무한대라면, 즉 2 부터 시작해서 일부러 중간에 break 구문을 만나지 않는 이상 계속 소수를 반환하는 방법도 있을 수 있는데, 예전에 구글링 통해 방법을 찾았던 적이 있음,

아래는, python 의 제너레이터 문법을 사용해서, n 을 지정하지 않아도 계속해서 소수를 반환하도록 한 방식을 사용한 풀이임,

```python
class Solution:
    def countPrimes(self, n: int) -> int:
        a = 0
        for x in g():
            if x >= n:
                break
            a += 1
        return a

def g():
    n = 1
    h = {}

    while True:
        n += 1
        if n in h:
            for x in h[n]:
                h.setdefault(n+x, []).append(x)
            del h[n]
        else:
            yield n
            h[n*n] = [n]
```

이 역시 에라토스테네스의 체 방식이 사용되었음, g 제너레이터에서 h 딕셔너리 안에 소수가 아닌 수들이 저장되는데, `{ n: [n 의 약수들 중 소수], ... }` 형태로 저장됨,

n 을 늘려가며 while 구문으로 순회, 만일 n 이 h 안에 없다면 소수이므로 바로 yield 하고, `{ n*n: [n] }` 을 h 에 저장,

소수가 아니닐때의 동작이 좀 어려울 수 있는데, `{ n: [a, b, c] }` 였다면, a, b, c 는 n 의 약수이고, 따라서 n 이 a, b, c 의 배수가 됨, 그래서 n 은 소수가 아니므로 h 에 저장되어 있었다고 생각하면 됨,

그리고 a, b, c 의 다음 배수도 소수가 아닌 수로 지정해야 하는데, 이는 각각 n+a, n+b, n+c 임, 이들을 다시 h 저장하도록 함, 그리고 더 이상 n 의 정보는 필요가 없으므로 h 에서 삭제하도록 되어있음,
