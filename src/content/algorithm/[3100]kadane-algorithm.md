## 카데인 알고리즘

동적계획법 알고리즘 중 하나, 어떤 데이터셋이 있다면 연속된 원소들로 이뤄진 부분 데이터셋을 구할 수 있을 것이고, 이들 중 합계가 최대인 값(즉 최대 부분합)을 구할 때 사용할 수 있는 알고리즘임,

[동적계획법](/blog/dynamic-programming-and-memoization)을 설명한 포스팅에 붙여볼까 했는데, 한 개 포스팅이 너무 길어질 것 같아 따로 소개함,

## 최대 부분합 구하기

쉽게 생각하면 가장 무식한 방법으로 구할 수 있음, 예를들어 데이터셋이 [a, b, c, d, e, f, ...] 와 같이 있다고 하면, 이중루프로 구현 가능함,

제일 바깥쪽 루프가 a 부터 시작해서 하나씩 순회한다고 하면, 안쪽루프는 바깥쪽 루프의 시작점부터 시작해서 다시 데이터셋의 끝까지 가면서 합계를 누적하고, 부분합 최대값이 나올 때마다 최대 부분합을 업데이트 하면 됨,

위 방식의 시간복잡도는 O(n^2) 이 되는데, 동적계획법 즉 카데인 알고리즘 사용하면 O(n) 시간복잡도로 문제를 해결할 수 있음,

위 동적계획법 포스팅 링크에서도 설명했지만, 동적계획법은 `초기값`과 `일반항`을 먼저 생각해야 함, 최대 부분합을 구해야하는 데이터셋이 X 이고, X 의 n 번째 인덱스까지 최대부분합을 f(n) 이라고 한다면...

> - 초기값: f(0) = X[0]
> - 일반항: f(n) = max(f(n-1) + X[n], X[n])

이 됨, 만일 데이터셋이 모두 양수라면 최대 부분합은 무조건 전체 데이터셋 원소들의 합계일 것임, 그러나 음수가 섞여 있다면 그 음수로 인해 부분합이 계속 커지지는 않음, 특히 특정 인덱스까지의 부분합 자체가 (-)마이너스가 된다면 아예 부분합 구하기를 그 인덱스부터 새로 시작하는 것이 나음,

이렇게 생각하면 일반항 부분 수식이 이해가 됨, n-1 단계까지의 최대 부분합에 n 단계의 값을 더한것 즉 `f(n-1) + X[n]`과, n 단계 값으로 그냥 새롭게 부분합을 시작하는 것 즉 `X[n]` 중에서 더 큰 값을 n 단계의 최대 부분합으로 보겠다는 것임,

# leetcode: 53. Maximum Subarray

[https://leetcode.com/problems/maximum-subarray/](https://leetcode.com/problems/maximum-subarray/)

숫자 원소로 채워진 nums 데이터셋에서 연속된 원소들로 이뤄진 최대 부분합을 구하는 문제,

위에서 언급한 방식으로 풀면 아래와 같음,

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        a = [0] * len(nums)
        a[0] = nums[0]

        for i, x in enumerate(nums[1:], 1):
            a[i] = max(a[i-1] + x, x)

        return max(a)
```

a 는 데이터셋 nums 의 i 인덱스까지의 최대 부분합을 저장하는 리스트로, 예를들어 a[5] 의 값은 nums 의 5 인덱스 원소가 제일 마지막 원소로 포함되었을 때의 최대 부분합임,

마지막엔 i 인덱스 까지의 최대 부분합들 중 제일 큰 값을 리턴하도록 함,
