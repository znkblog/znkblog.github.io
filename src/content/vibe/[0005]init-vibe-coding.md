개인사를 먼저 꺼내보자면, 고등학교 때 문과를 선택하고 대학에서 상경계를 전공했다. 그리고 나름 대기업이라 할 수 있는 곳에서 기획부서 배치받고 사회생활을 시작했다. 기획이라는 분야에서 벗어나본 적은 없는 것 같다. 그동안 워드/엑셀/파워포인트와 제일 친했으며, 보고서 작성이나 브리핑이 주로 하는 업무의 대부분이었다. 즉 개발이니 코딩이니 하는 분야하고는 전혀 연이 없었다.

하지만 2020년대 들어서 ai 혁명이라고까지 말할 수 있을 정도로 ai가 우리 삶에 깊숙히 관여하기 시작했다. 심지어 개발분야를 넘어 그동언 무관했던 업무나 분야에서조차 ai 활용은 물론, 바이브코딩까지 해서 일처리를 하기 시작했다.

20년전 첫 취업할 때 면접에서 받았던 질문 중 하나는 "ms오피스를 어느 정도까지 다룰줄 압니까?" 였었다. 만일 내가 지금 이시기에 면접을 받는다면 "ai를 어느 정도까지 다룰줄 압니까?"로 질문이 바꼈을 것이다.

선택을 넘어 필수인 시대가 다가오고 있음을 느낀다. 이제는 비전공 비관련업무라도 바이브코딩까지도 적당히 헐줄압니다 정도는 되어야 경쟁력을 갖출 수 있지않을까 생각이 든다.

본인의 경험으로 보면, 사실 전문가 수준으로까지 알 필요는 없다. 코드 자체는 ai가 작성해줄 것이기에, 적당히 이해하고, 실행하고, ai에게 지시하기만 해도 신세계가 열릴 것이다.

이 포스팅에서는 본인의 수준에서 바이브코딩으로 일처리를 할 때, 어떤 준비가 필요한지 기억을 더듬어 기록해본다.

## 배워둬야 할 것들

코딩을 아예 몰라도 바이브 코딩 가능하다고 들어본 분들도 있겠지만, 개인적인 생각으로는 코딩을 1g도 몰라서는 안된다. ai에게 정확한 지시를 내리기 위해, 그리고 ai가 작성해준 스크립트가  계획했던 것과 다르게 동작할 경우 빠르게 바로잡기 위해 필요하다. 코딩을 좀 알면 토큰 낭비도 줄일 수 있다.​

현재까지 본인의 바이브 코딩 활용 경험으로 보면, 프로그래밍 언어로는 데이터 분석에 많이 사용하는 언어인 python과 지금 화면에 띄워져 있는 본 블로그를 구성하는 웹페이지의 표준 언어인 html/css/javascript 정도만 알면 될 듯 하다. 전문가 수준으로까지는 필요없고 이들의 기초적인 문법과 스크립트 또는 코드를 실행할 수 있는 방법만 알면 된다.

이정도는 충분히 독학으로 배울 수 있다. 그리고 이런 유명한 프로그래밍 언어들은 학습할 수 있는 콘텐츠도 풍부하다. 개인적으로는 무료로 학습 콘텐츠를 쉽게 얻을 수 있는 위키독스나 생활코딩 같은 사이트를 추천해본다.

​

이 외에도 바이브 코딩 하다보면, 생소한 it 관련 언어(기획쟁이들은 들어본 적도 없는...)들을 ai가 종종 내뱉는 경우가 있다. 예를들면 "현재 csv 파일 인코딩이 utf-8 이라, 엑셀에서 직접 열면 한글이 깨질 수도 있습니다." 와 같은 말을 접한다면, 인코딩? utf-8? 뭐지? 하면서 당황할 수도 있다. 그럴 땐 ai에게 즉시 물어보면서 그때그때마다 익혀나가야 한다.

​

​

설치해야 할 것들

바이브 코딩에 있어 제일 중요한 도구는 ai 자체가 될 것이다. 어떤 ai든 아무거나 사용해도, 본인이 원하는 수준에서는 어느정도 만족할만한 결과들을 다 보여주는 것 같았다.

​

다만, 로컬 pc에 있는 파일이나 설정을 직접 조작해야하기 때문에, 가장 일반적으로 접할 수 있는 방법인 ai 웹사이트를 사용하지는 않고, cli 버전을 설치해 사용하였다. codex cli, claude cli, copilot cli 등등 웬만한 ai 들은 모두 다 설치 가능하다.

​

참고로 cli 는 Command Line Interface 의 약자로, cmd 나 powershell 같은 터미널 화면에서 조작하는 환경을 뜻한다. 즉 터미널에서 ai 를 띄운다고 생각하면 된다. 본인처럼 나이가 좀 있으신 분들은 ms-dos 감성이 묻어날 것이다.

​

그리고 바이브 코딩이란 사용자는 자연어로 지시하면 ai가 코드로 표현하는 것인데, 간단한 수정을 원할 땐 ai가 생성한 코드를 직접 수정하는 게 더 빠른 경우도 있다. 적당한 코드 편집기도 필요한데 주로 vscode를 사용했다.

​

ai cli 버전과 vscode 만 설치하면 된다. 설치법에 대해서는 링크를 참고하거나 ai에게 물어보면 된다.

​

실제로 바이브 코딩할 때는, ai 가 관리자 권한이 필요하다는 경우가 있어, ai cli 버전은 관리자 권한 있는 powershell에서 실행하고, 동일한 폴더를 vscode로도 띄워서 사용했다.

​

​

알아둬야 할 것들

어떤 프로젝트가 있을 때 먼저 readme 를 읽어보세요 하는 경우가 있다. 프로젝트의 개요와 개괄적인 현황들을 한번에 파악할 수 있는 내용들이 담겨있다. ai cli 버전 대상으로 readme 역할을 하는 것은 AGENTS.md 파일이다. (참고로 md 파일은 마크다운 형식의 파일인데, 잘 모른다면 이 역시 ai에게 물어보자.)

​

웹페이지에서 ai 사이트에 접속하면 보통 지난 채팅을 이어나갈 수 있도록 채팅방을 선택할 수 있다. 그렇다면 cli 버전에서는? pc를 껐다가 다시 켰을 때 계속 작업을 이어나가려면? 이런 역할을 하는게 AGENTS.md인 셈이다.

​

개인적으로는 ai cli 버전을 처음으로 띄우면 의도적으로 이 파일을 먼저 읽어두라고 지시한다. 그리고 작업을 종료하기 적전에 현재까지 작업했던 내용을 바탕으로 AGENTS.md 파일을 업데이트하라고 지시하는 편이다.
