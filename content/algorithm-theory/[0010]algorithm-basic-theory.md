## 알고리즘과 복잡도
- 알고리즘은 주어진 문제를 해결하거나 목표를 달성하기 위해, **입력된 데이터를 처리하는 일련의 논리적 절차**를 뜻함
- 복잡도는 입력된 데이터의 크기 **N이 증가할 때 알고리즘이 사용하는 시간 또는 메모리의 증가율 정도**를 뜻하며, 크게 시간복잡도와 공간복잡도로 구분 가능
- 복잡도는 일반적으로 Big-O 표기법으로 나타내며, 증가율의 상한선(더 높은 증가율로 넘어가지는 않음)을 나타냄

## Big-O 표기법
- 입력된 데이터 크기를 `N`, `N`이 증가함에 따라 시간 또는 메모리의 증가율 상한선이 `3N² + 5N + 10` 일 경우, 가장 빠르게 커지는 차수만 남기고 해당 차수의 계수를 제거하여 표현함
```plaintext
O(3N² + 5N + 10) → O(N²)
```
- 아래와 같이 O(N) 작업이 k(k < N)개만큼 연속될 경우 O(kN)이 되며 위 정의에 따라 최종적으로는 `O(N)`이 됨
```python
for i in range(N):  # O(N) 작업
    pass
...
...
for i in range(N):  # O(N) 작업
    pass
```
- 아래와 같이 O(N) 작업이 중첩될 경우 O(N*N)이 되며, 위 정의에 따라 최종적으로는 `O(N²)`이 됨
```python
for i in range(N):      # O(N) 작업
    for j in range(N):  # O(N) 작업
        pass
```
- 크기가 다른 두개의 데이터 N, M이 입력될 경우 연속이면 `O(M+N)`으로, 중첩이면 `O(MN)`으로 표현하기도 함

## 주요 시간복잡도
- N에 따른 연산 횟수(시간) 증가율을 오름차순으로 표현

| 복잡도 | 명칭 | 의미 | 사례 |
|--------|------|------|------|
| O(1) | 상수 | N에 관계없이 연산 횟수 일정 | 배열 인덱스 접근, 해시 조회 평균 |
| O(log N) | 로그 | 연산 횟수 매우 느리게 증가 | 이분 탐색 |
| O(N) | 선형 | N에 비례하여 연산 횟수 증가 | 배열 한 번 순회 |
| O(N log N) | 선형 로그 | 입력을 여러 단계로 분할, 각 단계에서 전체 입력 처리 | 병합·힙 정렬 |
| O(N²) | 제곱 | N의 모든 쌍을 확인하는 수준으로 증가 | 이중 반복문 배열 순회 |
| O(N³) | 세제곱 | N의 모든 세쌍을 확인하는 수준으로 증가 | 플로이드–워셜, 삼중 반복문 배열 순회 |
| O(2ⁿ) | 지수 | N이 하나 증가할 때마다 경우의 수가 약 두배로 증가 | 모든 부분집합 |
| O(N!) | 팩토리얼 | N 원소의 모든 가능한 순서를 확인 | 모든 순열 |

## 주요 공간복잡도
- N에 따른 메모리(공간) 증가율을 오름차순으로 표현, N 크기의 입력된 데이터가 아닌 알고리즘 수행 과정에서 **추가적으로 필요한** 메모리를 의미함에 주의

| 복잡도 | 명칭 | 의미 | 사례 |
|--------|------|------|------|
| O(1) | 상수 | 입력 크기와 관계없이 일정한 공간 사용 | 변수 몇 개, 제자리 정렬, 투 포인터 |
| O(log N) | 로그 | 입력이 줄어드는 재귀 호출 스택 | 이분 탐색 재귀, 균형적인 분할 정복 |
| O(N) | 선형 | 입력 크기에 비례하는 공간 사용 | 1차원 배열, 해시맵, 방문 배열, 깊이 N인 재귀 |
| O(N²) | 제곱 | 입력 크기의 제곱에 비례 | 2차원 배열, 인접 행렬, 2차원 DP |
| O(2ⁿ) 이상 | 지수 | 부분집합별 상태 저장 | 비트마스크 DP |
| O(N!) 이상 | 팩토리얼 | 순열별 상태 저장 | 순열 상태 DP |
