# 프로젝트 개요

EPSG:5174 좌표로 정의된 격자별 음식점 수를 한국 지도 위에 시각화하는 단일 HTML 지도다. 사용자는 HTML 파일을 브라우저에서 열어 격자 분포를 살펴보고, 격자를 클릭해 격자 ID와 음식점 수를 확인할 수 있다.

# 기술 스택 및 외부 의존성

- **HTML/CSS/JavaScript**: 지도 화면, 왼쪽 범례, 상태 메시지와 상호작용을 한 파일에 구현한다.
- **Leaflet 1.9.4**: 웹 지도, 지도 이동·확대/축소, 배경 타일 및 격자 타일 레이어를 담당한다.
- **proj4js 2.11.0**: 원본 EPSG:5174 좌표와 지도 좌표계 간 변환에 사용한다.
- **배경 지도**: `https://tile.openstreetmap.de/{z}/{x}/{y}.png`의 OpenStreetMap 타일을 사용한다. Leaflet 및 proj4js 라이브러리는 unpkg CDN에서 불러온다.
- 외부 라이브러리와 지도 타일을 불러오므로 HTML을 사용하려면 인터넷 연결이 필요하다. API 키는 사용하지 않는다.

# 데이터 및 좌표

- 원본 데이터 파일은 `격자배치결과.csv`다. CSV 칼럼은 `격자ID`, `격자좌상단좌표정보(X)`, `격자좌하단좌표정보(Y)`, `음식점카운팅`이다. Y 칼럼명은 `좌하단`으로 되어 있지만 좌표값은 격자 좌상단의 Y 좌표다.
- 격자 한 칸은 EPSG:5174 기준 1,000m × 1,000m다.
- 전체 격자는 X=-10,000, Y=565,000을 좌상단 원점으로 하는 556열 × 609행, 총 338,604칸이다.
- 격자 ID는 행 우선 순서로 연속한다. 셀의 행·열을 알면 `G` 접두사와 6자리 숫자로 ID를 계산할 수 있다.
- 음식점 수 범위는 0~1,564다. 원본 CSV에서 음식점 수가 1 이상인 격자는 25,916칸이다.
- CSV 데이터는 `음식점격자지도.html` 내부에 직접 포함한다. 파일 크기를 줄이기 위해 음식점 수가 0인 행은 포함하지 않는다. 생략된 셀은 음식점 수 0으로 취급하고 투명하게 표시한다.
- 좌표 변환과 격자 배치 시 CSV 좌표를 EPSG:5174 원본 좌표계로 해석한다.

# 지도 동작 및 표시 규칙

- 음식점이 있는 셀은 반투명한 색상으로 표시하고, 음식점 수가 0인 셀은 완전히 투명하게 둔다.
- 왼쪽 범례는 투명한 0개 항목과 5개의 양수 구간으로 구성한다. 초기 구간은 `1–10`, `11–50`, `51–100`, `101–200`, `201–1564`다.
- 범례에서 처음 네 구간의 상한값을 편집할 수 있다. 값은 오름차순의 정수여야 하며, 유효하지 않은 변경은 적용하지 않는다.
- 격자 표시는 커스텀 Leaflet `GridLayer`에서 지도 타일 단위로 그린다. 지도를 이동하거나 확대·축소할 때 격자가 배경 지도와 함께 움직이고 크기가 바뀌어야 한다.
- 전체 격자를 기준으로 클릭 위치의 격자 ID와 음식점 수를 팝업에 표시한다. 음식점이 0인 격자도 계산된 ID와 `0개` 정보를 확인할 수 있다.
- 행정구역 경계·검색·팝업은 현재 구현 범위에서 제외한다.
- HTML에 표시되는 제목, 안내, 상태 및 오류 문구는 경어체로 작성한다.

# 작업 지침

- 사용자가 명시적으로 진행을 요청하기 전에는 시각화 파일을 만들거나 조사하지 않는다.
- 데이터 구조, 좌표 원점, 격자 크기, 전체 행·열 수를 변경할 때는 코드의 파싱·렌더링·클릭 계산 및 이 문서를 함께 갱신한다.
- CSV 최적화 시 0개 셀의 투명 표시와 전체 격자 ID 계산 동작을 보존한다.
- 렌더링을 수정한 뒤에는 스크립트 문법, 내장 데이터, 서로 다른 축척에서의 격자 표시 및 이동·확대/축소 동작을 검증한다.
